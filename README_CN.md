# 🔺 mu-pyramid-principle · 金字塔原理逻辑教练

> 不讲理论只管落地。贴一段文字就能跑 7 类逻辑病诊断、MECE 校验、SCQA 变体选择，输出重组后的金字塔结构和优化文稿。
>
> 📚 基于 Barbara Minto《金字塔原理》方法论。

### 💡 使用场景示例

📄 **"这份季度报告帮我看看逻辑对不对"**
把文本贴进来，直接跑 7 类逻辑病诊断：结论缺失、以下不统上、分类交叉、逻辑跳跃、MECE 不全、演绎断链、事实判断混淆——每一处都引用原文、标注严重度、给出修复建议。

🔺 **"帮我用金字塔结构重新组织"**
诊断完毕后自动选择自上而下或自下而上的构建路径，把你的要点重组为经过 MECE 校验的金字塔结构，输出带 SCQA 序言的完整优化文稿——全程保留你的核心信息不丢失。

🎯 **"我有些想法，但不知道怎么组织"**
引导模式带你走完：你想让读者做什么？他们已经知道什么？什么阻碍了他们接受你的观点？——然后提炼一句话结论，拆解 3-5 个 MECE 子论点，生成完整文稿。

🔍 **"方案写完总觉得哪里不对"**
"论证类比"四字诀一秒排查：第一句是不是完整判断句？每个论点有没有理由支撑？分组不重不漏吗？组内有排序吗？

📝 **"帮我写个开头，这份报告该怎么起笔"**
四种 SCQA 变体——标准式、行动式、冲突式、提议式——根据你的听众和场景自动选型。一棵决策树帮你判断，不用猜。

🏋️ **"逻辑训练，练一下"**
四种训练题型：事实 vs 判断、演绎 vs 归纳、MECE 找漏洞、金字塔重组——每次反馈都先肯定做对的部分，再解释哪里需要改。

📊 **"竞品分析的素材一堆，不知道怎么归类"**
自下而上构建：罗列所有素材 → 按关系归类（MECE）→ 每组一句话总结 → 提炼总论点 → 自上而下验证一致性。

💼 **"述职材料怎么写？开头放什么"**
引导模式 → 自上而下 → 行动式 SCQA：结论先行的述职稿，先讲成果再讲支撑，抓住管理者注意力。

### ✨ 核心亮点

#### 🔍 7 类逻辑病诊断 —— 引用原文、标注严重度、给修复

每次诊断扫全部 7 类，逐条引用原文原话，标注严重程度（🔴 致命 / 🟡 中度 / 🟢 轻微），并给出具体修复建议。

| # | 病名 | 严重度 | 检测什么 |
|---|------|--------|---------|
| 1 | 结论缺失 | 🔴 致命 | 全文没有一句判断句——读完不知道"所以呢" |
| 2 | 以下不统上 | 🔴 致命 | 子论点各自成立，但加在一起推不出父论点 |
| 3 | 分类交叉 | 🟡 中度 | 并列项有重叠——同一个东西能归入多个分类 |
| 4 | 逻辑跳跃 | 🟡 中度 | 两个论点之间少了中间步骤——直接跳到结论 |
| 5 | MECE 不全 | 🟡 中度 | 分类不穷尽——有明显遗漏的维度 |
| 6 | 演绎断链 | 🟢 轻微 | 大前提缺失或结论无法从前提推出 |
| 7 | 事实判断混淆 | 🟢 轻微 | 主观判断当客观事实说，没有依据标注 |

#### 🧩 "论证类比"四字诀

借鉴中文古典修辞的 4 秒快速校验法，用来验证金字塔结构的每一层：

| 论（结论） | 证（证据） | 类（分组） | 比（排序） |
|:---:|:---:|:---:|:---:|
| 结论先行 | 以上统下 | 归类分组 | 逻辑递进 |
| 第一句是完整判断句？ | 每个论点有理由支撑？ | 不重不漏？ | 组内有排序？ |

#### 📐 SCQA 四变体 —— 根据场景自动选型

序言变体的选择不靠猜，而是根据听众认知、决策紧迫度、情感抵抗程度自动判断。

| 变体 | 适用场景 | 结构 |
|------|---------|------|
| 标准式 | 正式汇报 | S→C→Q→A 完整展开 |
| 行动式 | 紧急决策 | S→A→C→Q（结论前置）|
| 冲突式 | 说服对方 | C→S→Q→A（痛点开场）|
| 提议式 | 方案推荐 | Q→S→C→A（问题导向）|

#### 🔺 双模式交互 —— 快捷 & 引导

| 模式 | 行为 | 何时触发 |
|------|------|---------| 
| 🚀 快捷模式（默认） | 贴文本 → 7 类诊断 → 金字塔重组 → 优化文稿 | 贴了文字 + 触发词如"帮我理清逻辑""这段结构有问题" |
| 💬 引导模式 | 对话引导，从模糊想法构建金字塔 | 说"帮我理清思路""我想表达 XX 但不知道怎么组织" |

#### 🏗️ 自上而下 & 自下而上双路径

两条构建路径，根据你手头的素材自动选择：

```
自上而下（你有明确观点）：
  论点 → 预判读者疑问 → 3-5 个 MECE 子论点 → 每个配论据+数据 → SCQA → 输出

自下而上（你有散乱素材）：
  罗列要点 → 归类分组 → 每组一句话 → 提炼总论点 → 验证一致性 → SCQA → 输出
```

#### 🏋️ 逻辑训练模式 —— 4 种题型

说"逻辑训练"或"练一下"就能进入教练模式：

| 题型 | 你做什么 | 你练什么 |
|------|---------|---------|
| A. 事实 vs 判断 | 判断 5-7 个句子是事实还是判断 | 区分客观与主观 |
| B. 演绎 vs 归纳 | 识别一段论证的推理方式 | 发现前提不保证结论的情况 |
| C. MECE 找漏洞 | 找出一个分类方案的交叉和遗漏 | 练出干净分组的直觉 |
| D. 金字塔重组 | 把打乱的论点和论据重新组织 | 练完整结构重建 |

### 🔒 安全与隐私

- **纯本地运行** —— skill 只是几个 Markdown 文件，由你的 Agent 读取。不安装任何东西，也不执行任何东西。
- **零网络请求** —— 没有 API 端点、没有外部服务、全程不发起任何远程调用。
- **零遥测** —— 无使用统计、无埋点、无回传。压根没有任何"能够"收集数据的代码。
- **零依赖** —— 不引入 npm / pip / 第三方包，因此不存在供应链攻击面。
- **文本不出你的 Agent** —— skill 不新增任何存储、日志或持久化，你分析过的文档不会被留下。
- **完全可审计** —— 一共 4 个 Markdown 文件，全部人类可读，十分钟能通读一遍。
- **无需任何凭证** —— 不需要 API Key、Token 或账号。
- **保全你的信息** —— IRON LAW 明确禁止过度删减；重组 ≠ 重写，你的要点在每次重建中都会保留。
